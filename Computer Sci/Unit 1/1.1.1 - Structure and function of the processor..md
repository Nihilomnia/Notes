## Parts of the CPU
### The Control unit
Coordinates all activities of the CPU.

Directs flow of data between the CPU and other devices.

Accepts the next instruction, decodes it handles its execution, and stores the resulting data back into memory or registers.

Sends memory read and write requests to main memory on the control bus, as well as other command and control signals such as bus requests, bus grants, interrupt requests etc 

Makes extensive use of the status registers and clock.

Coordinates and communicates with all parts of the CPU.


### Program Counter  (PC)
Holds the address of the next instruction to be executed. 

This could be : 

- The next instruction in a sequence of instructions
- The address to jump to if the current instruction is a command to jump or branch this would be copied from the current instruction register  (CIR)



Has a close relationship with the [Memory Address Register (MAR)](<#Memory Address Register (MAR)>). At the start of every new fetch- decode- execute cycle (More on that later), the address held in the PC is copied to the MAR.

### Memory Address Register (MAR)

This holds the address of the memory location from which data or an instruction is to be fetch or to which data is to be written.

Sends these addresses to memory down the address bus.


### Memory Data Register (MDR)

Used to temp store the data which is read from or written to memory.

Sometimes known as the memory buffer register (MBR) and often nicknamed the *"gateway to the processor"*. 

All data to and from the memory must travel down the data buss and pass through the MDR

### Current Instruction Register

Holds the current instruction being executed.

The contents of the MR are copied to the CIR if it was an instruction.

Contains the opcode and the operand(s) of the current instruction.

An instruction if made of  the opcode then the operands 

For example, a machine code instruction to load the contents of location 1000 to the the ALU (More on that later) might look like : LDA 1000


### Arithmetic Logic Unit (ALU)

Performs arithmetic and logical operations on data.

Arithmetic operations on fixed and floating point numbers: 
- ADD
- SUBTRACT 
- MULTIPLY 
- DIVIDE 

Bitwise shift operation left and right 

Boolean logic operations: 
- Comparison
- AND
- OR 
- XOR 

Often uses general-purpose registers to temporarily hold the result of calculations such as the accumulator. 

### Accumulator (ACC)

One of a number of general-purpose registers that modern CPUS have.

Data or control information is often stored in them them.

A CPU may have many general-purpose registers for storing temp data while instructions or calculations are being carried out.

Typically, the more general - purpose registers a processor has, the faster it may operate. 

The results of calculations carried out by the ALU can be temp stored here.

## Fetch Decode Excuse Cycle (FDE)

### The standard


#### The Fetch Stage 
1. The program counter is checked, as it holds the address of the next instruction to be executed  (In this case lets just say mem address 0000)
2. The address stored is then copied into the MAR. 
3. The address is then sent along the address bus to main memory, where it waits to receive a signal from the control bus.
4. As we want to read the data that is stored in mem address 0000, the control unit sends a read signal along the control bus to main memory
5. The contents stored in mem address 0000 can now be sent along the data bus to the memory data register.
6. As we are currently in the process of fetching an instruction, the data received by the MDR from memory now gets copied into the CIR.
7. The instruction has now been fetched.
8. Before we proceed to the decide phase, we must increment the contents of the program counter so the address it contains points to the next instruction to be executed. 

#### The Decode Stage 

1. The instruction held in the CIR is now decoded by the decode unit.
2. The instruction is made up of two parts: The Opcode (what to do) and The Operand (What to do it to - Such as actual data or an address where data is found)
   
   If the instruction is in 8 bits the first four bits would be the opcode and the remaining 4 would be the operand 
   
   For example  0101 0101 using the decode table from before means load the value of mem address 0101 to the ACC
   
   In this case since we are using 4 bits for both the opcode  there only a maximum of 16 different opcodes (2^4 = 16) 



### The Execute Stage 
1. We now send the address 0101 to the memory address register 
2. As we want to read the data that is stored in mem address 0101, the control unit then sends a read signal along the control bus to main memory.
3. The contents stored in mem address 0101 can now be sent along the data bus to the MDR.
4. The contents of the MDR are now copied to the ACC and the instruction is now complete
   
   

### Branching 

Assume that in our CIR we have an instruction with the opcode of 0110 

That's opcode means BRA or "Branch Always"

This replaces the value held in the PC with the contents of the operand from the CIR which in this case we would say was 1001

When the next fetch cycle begins, the program counter is checked.

As its contents have been previously updated to a new memory location and not just incremented, the program can jump around in memory.

## Factors that effect the performance of the CPU

### Clock Speed 

Measured in Hertz (Hz)

Number of cycles per second 

Modern processors operate at billions of cycles per second  - Gigahertz (GHz).

For example 3.2 GHz clock speed = 3.2 billion instructions can be fetched per second.


### Cache Size 

Temporary storage of data and instructions being written to and read from.
Located on or near the CPU.
Stores copies of recent data and instructions 
Much quicker to access than RAM 
This allows us to avoid getting instructions and data from RAM as RAM is much slower.

### Number of Cores 

A core is, in simple terms, a complete copy of a CPU.

A quad-core processor would have four separate processing units, each with its own 

- Registers 
- ALU
- Accumulator
- Control unit, etc 


CPUs with multiple cores have more power to run multiple programs at the same time.

Note: Doubling the number of cores doesn't simply double the overall speed.

CPU cores have to communicate with each other, which takes time.

Many programs are not designed to make use of multiple cores.



## Pipelining

Without pipelining the various different steps in the F-D-E cycle have to take place one after the other.

In this example we can see that while the next instruction is being fetched, the ALU, which carries out mathematical equations is sat idle.

This isn't a very efficient use of the ALU!

By using pipelining the next instruction can be fetched while, at the same time, the processor is performing arithmetic or logic operations in the ALU for a previous instruction.

In this way we can make efficient use of the various registers and on board CPU cache and it allows different part of instructions across multiple stages to be held in different registers at the same time.

Processor pipelining is often divided into :

1.  Instruction pipeline  - This consists of the various stages an instruction must move through the processor.
   
2. Arithmetic pipeline  - This consists of the parts of an arithmetic operation that can be broken down and overlapped as they carried out.


Pipelining is very common in today's processors allowing multiple instructions to execute simultaneously.

An event called flushing the pipe occurs when instructions that are in the process of the FDE cycle is gotten rid of because it wasn't needed. For example this happens during branching instructions and this is the reason why a program with a lot of branching instructions might not benefits as much from Pipelining


### Von Neumann,Harvard and  Contemporary  Architectures

Both Von Neumann and Harvard are examples of older computer architectures, having originated in the 1940s.

### Von Neumann 

Shared memory space for instruction and data.
Instructions and data are stored in the same format.
A single control unit or processor follows a linear fetch, decode execute cycle.
One instruction at a time.
Registers are used as fast access to instructions and data.
![](</Computer Sci/Images/Pasted image 20260722205557.png>)

### Harvard Architecture 

Instructions and data stored in separate memory units.
Each has its own bus.
Reading and writing data can be done at the same time as fetching an instruction.
Used by RISC processors
